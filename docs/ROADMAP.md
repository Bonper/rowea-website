# Roadmap — ROWEA Global Weather Platform

## Phase 1 — Brand, Discovery & Platform Routing (`rowea-website`) *(Current)*

- Bilingual (`EN` default + `VI`) marketing and product overview website.
- Light & Dark theme support with system preference detection and `localStorage` persistence.
- Nine dedicated routes with build-time static prerendering, SEO metadata, `sitemap.xml`, and `robots.txt`.
- Multi-signal best-effort device detection with manual 6-platform selection.
- Honest **Coming Soon** / **Planned** labeling across ecosystem modules, APK slots, and Premium tier.
- GitHub Actions CI and Cloudflare Pages static deployment readiness.

## Phase 2 — ROWEA Weather Core Application *(Planned)*

- Launch **ROWEA Weather** web/PWA client and verified meteorological data pipelines.
- Publish initial signed **Android APK** builds with real version tags, file sizes, and SHA-256 verification checksums in `src/config/releases.ts`.
- Activate interactive PWA installability (`beforeinstallprompt` / service worker caching) on the application origin.

## Phase 3 — Expanded Ecosystem & Premium *(Planned)*

- Progressive rollout of **ROWEA Radar**, **ROWEA Alerts**, **ROWEA Air**, and **ROWEA Climate**.
- Publish official **ROWEA Premium** pricing, subscription infrastructure, and updated Privacy/Terms disclosures prior to launch.
